# Build notes - curated showcase revision

This revision removes automatic MiniMax-folder ingestion.

- Deleted `SYNC-MINIMAX.bat` and `tools/sync_minimax.py`.
- Added `showcase/` as the sole deliberate source folder.
- Added `tools/import_showcase.py` and `BUILD-SHOWCASE.bat`.
- `START-SITE.bat` now rebuilds only from `showcase/` before serving.
- Native MiniMax YAML remains supported, so title/version/duration/cover/prompt/
  lyrics do not need duplicating into another hand-maintained schema.
- Chosen render filenames still provide CFG, steps and seed metadata when those
  fields are encoded in the filename.
- Multiple matching renders are imported only when you deliberately place those
  files into `showcase/`.
- FLAC/WAV are ignored generally but explicitly permitted inside `showcase/`,
  preventing accidental commits from unrelated working directories.
- Generated runtime audio, artwork derivatives and track records are ignored by
  Git and regenerated by the local build or GitHub Actions.
- The cassette remains latched and glowing in its wall position during playback.

## v5.1 hotfix

- Removed the accidental runtime dependency on the third-party `markdown` or `mistune` packages.
- `tools/build_docs.py` now contains a dependency-free Markdown renderer for the documentation subset used by this site.
- Verified the full curated build sequence with no selected audio: import, artwork preparation, catalogue/docs generation and link validation all complete successfully.
- A YAML with no matching hand-picked audio remains a warning and produces an unavailable cassette by design.

## v5.2 cassette-wall visual revision
- Reworked the showcase from spaced "cards" into one dense physical cassette wall.
- Removed title/version text from cassette faces and removed per-cassette copy/ENGAGE chrome from the wall.
- Increased the artwork/label height and overlaid the reel window into the lower label area.
- Added subtle shell variation and tiny placement imperfections for a collected-wall appearance.
- Selected cassette remains in-place, depresses/latches, glows amber, and spins its own reels during playback.
- Track title/version remain available in the wall transport monitor after selection and via accessible button labels.


## v5.3 genre / version / EQ revision
- Wall is grouped into build-time genre sections using the YAML `genre` field.
- Releases sharing a title/composition are rendered as one adjacent cassette run, ordered by song version and then generation parameters.
- Importer now preserves `model` and `state` from the shared YAML schema instead of hard-coding MiniMax Music 3.
- `inspiration` is a dedicated catalogue field and is shown in the player monitor on selection.
- Added a real five-band Web Audio equalizer at 60 Hz, 250 Hz, 1 kHz, 4 kHz and 12 kHz with +/-9 dB range, persistent settings, reset-to-flat, and automatic boost headroom.
- VU meters now analyse the post-EQ signal.
- Cassette shell changed to a near-square 1.14:1 format with a true square artwork panel, so square album covers are no longer cropped into a wide tape label.
- Missing genre is deliberately labelled `Unclassified`; the importer does not guess a category from the prompt.
